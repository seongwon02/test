git이 파일을 저장하는 장소를 respository라고 한다.
이를 저장소라고 하는데 실제로는 온라인 repository를 많이 사용한다. << github

원격저장소 쓰는 이유는 내 컴퓨터에서 만들어놓은 저장소를 백업하기 위함.
1. 작업폴더 하나 생생 후 git init 작성
2. git branch -M main 작성 (github는 기본 브랜치 이름을 master가 아닌 main으로 강요함.)
3. 파일 커밋 한 후 git push -u 원격저장소주소 올릴로컬브랜치명
git에서 변수문법 사용가능
    git remote add 변수명 원격저장소주소
    또는
    git push 할 때 -u 추가하면 주소 기억하라는 뜻
    따라서 got push만 해도 깃허브에 저장됨

-github로 협업하는 법
팀원들은 코드 짜고 git push ~~~ 하면 끝
소스코드는 깃허브에서 다운받거나 git clone 원격저장소이름 작성하여 다운
*단 팀원 깃허브 등록을 해놔야 git push 가능

git pull 원격저장소주소 브랜치명 << 원격 저장소에서 로컬 저장소로 이동(팀원들이 새로 작성한 코드를 내 로컬저장소로 이동)
*원격저장소 최신 내용들이 로컬저장소에 있을 때에 git push 가능

요약: git push 전에 git pull 먼저 ㄱ
